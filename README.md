# Netflix Content Strategy Analysis (2023)
Analysis of Netflix Content Strategy using Python &amp; Plotly


This project analyzes Netflix’s 2023 content strategy using Python, Pandas, and Plotly.
It explores:
- Viewership trends
- Content release patterns
- Language-wise engagement
- Seasonality patterns
- High-impact release dates
- Movies vs Shows analysis
- Weekly & monthly viewership patterns

## Tools Used
- Python
- Pandas
- Plotly (interactive visualizations)
- Jupyter Notebook

## Dataset
The dataset contains:
- Title
- Release Date
- Content Type
- Language
- Hours Viewed
- Season
- Day of Week

## Notebook
📓 **netflix_strategy_analysis.ipynb**

## Visualizations Created
- Viewership by content type
- Language viewership distribution
- Monthly viewership trends
- Seasonal viewership patterns
- Weekly release vs viewership
- Top 5 titles analysis
- Holiday release analysis
